# 75-second walkthrough script

0–12 seconds: “I tested a narrow question: does turning purchase history into a persona improve prediction of future purchases?” Show the research question and sample size.

12–28 seconds: Show the five-condition Brier chart. “Persona summaries increased prediction error relative to structured history; gradient boosting had a lower Brier score.”

28–43 seconds: Open the direct-comparison panels. State the paired differences and intervals, emphasizing that the observations are matched and households are the resampling unit.

43–62 seconds: In the local report, open one losing and one helping example. Follow source history → generated persona → prediction → held-out label → squared-error contribution. Describe observations, not a proven mechanism.

62–75 seconds: “This is one model and one purchasing task, not proof of general population fidelity. The code and run artifacts make the result auditable; the next step is a frozen independent replication.”

Record only the report window. Keep .env and account pages out of the recording. This file is a script, not a produced video.
